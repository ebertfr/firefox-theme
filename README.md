# All Black Pro [True AMOLED Theme] for Firefox

A 100% pure black (`#000000`) theme for Mozilla Firefox built for true dark mode experience on AMOLED and OLED screens.

---

## Features

* **100% Pure Black Background**: `#000000` applied across tabs, toolbars, menus, and sidebars.
* **Zero Outlines**: Removes gray borders and outlines for maximum contrast.
* **Crisp Readability**: Optimized text contrast for easy reading.

---

## Installation

### Option 1: Firefox Add-ons (Recommended)
Install directly from [Firefox Browser Add-ons](https://addons.mozilla.org/).

### Option 2: Manual Installation
1. Download the `manifest.json` file from this repository.
2. Open Firefox and go to `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on...** and select your `manifest.json` file.
